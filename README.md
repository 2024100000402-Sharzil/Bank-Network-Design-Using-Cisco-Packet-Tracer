# Bank-Network-Design-Using-Cisco-Packet-Tracer
This project designs a bank communication network using Cisco Packet Tracer. It connects one Head Office and two branches using routers and switches. The network uses IPv4 subnetting from 192.168.99.0/24 and includes routing, DHCP, DNS, and Web Server configuration for communication and centralized network services.
A complete bank communication network simulation built using Cisco Packet Tracer.

The network contains:
- 1 Head Office
- 2 Branch Offices
- 3 Routers
- 3 Switches
- DHCP Server
- DNS Server
- Web Server
- Multiple PCs

Features:
- IPv4 subnetting using 192.168.99.0/24
- Static routing between branches
- Automatic IP allocation using DHCP
- DNS name resolution
- Web server hosting
- Inter-branch communication
- End-to-end connectivity testing

Technologies Used:
- Cisco Packet Tracer
- IPv4 Addressing
- Subnetting
- Static Routing
- DHCP
- DNS
- HTTP/Web Server

The project simulates a real-world enterprise bank network infrastructure and demonstrates practical networking concepts including routing, LAN design, and centralized network services.
